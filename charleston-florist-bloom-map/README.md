# Bloom Map — Wedding Floral Brief Builder

An independent MVP prepared for Charleston Florist. Couples can organize event details, palette and style direction, floral areas, rough counts, priorities, repurposing, venue logistics, references, and unresolved questions into one consultation brief.

The app intentionally does not claim flower inventory or seasonality, identify or promise exact stems, calculate exact quantities, quote, hold a date, approve venue logistics, schedule a consultation, collect payment, or place an order.

Plain HTML, CSS, and JavaScript. No dependencies, account, tracking, or data persistence.
