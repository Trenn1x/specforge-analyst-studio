# Happy Hounds Wedding Paw Plan

A dependency-free, phone-friendly wedding pet-care planning MVP created as an independent concept for Happy Hounds Dog Walking & Pet Sitting in Charleston, South Carolina.

The planner helps a couple organize their event, pet temperament and care notes, the pet’s wedding role, transportation handoffs, and backup contact. It turns those details into a live run-of-show and an inquiry brief that can be copied, saved on the device, or emailed to Happy Hounds.

This MVP does not confirm availability, a booking, service fit, timing, or pricing. A finished mobile version could add event-day alerts, handler check-ins, photo updates, and a “safely home” status feed.

## Files

- `index.html` — accessible planner interface
- `styles.css` — responsive visual system
- `app.js` — planning state, timeline generation, local save, copy, and email handoff
