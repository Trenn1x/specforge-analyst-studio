# Southern Pours — Pour Plan & Venue Fit

An independent MVP concept for Southern Pours, a Charleston-area mobile-bar business.

The planner helps a prospective customer organize event details, a rough 30 × 15 ft setup zone, venue permission, access, guest preferences, a package conversation starting point, décor interests, and questions to confirm with the owner. It produces a copyable brief and can open a prefilled email draft.

## Boundaries

This concept does not check availability, hold a date, approve a venue, calculate alcohol, decide staffing, provide legal advice, quote, collect payment, place an order, or create a booking.

## Files

- `index.html` — semantic app shell
- `styles.css` — responsive presentation
- `app.js` — live fit flags, gap list, brief generation, and draft handoff

Built as a speculative local-business MVP by Tom in Charleston, SC.
