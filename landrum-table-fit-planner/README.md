# Landrum Table Fit Planner

An independent MVP concept for Landrum Tables in Charleston, South Carolina. The planner lets a prospective customer compare a rectangular table starting point with room dimensions and open clearance, capture build and material direction, prepare access photos, and generate an email-ready custom-project brief.

The planner does not quote a project, reserve wood, verify sentimental material, guarantee seating or fit, promise lead time or delivery, submit an order, or represent live Landrum inventory. Capers and Landrum Tables confirm every actual build decision.
