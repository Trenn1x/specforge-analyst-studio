# Against The Grain Piece Planner

A dependency-free GitHub Pages build of the furniture commission brief planner.

## What it does

- captures piece type, measurements, surface, and condition
- organizes finish direction, hardware, timing, and transport context
- generates a tailored photo checklist and review flags
- saves the plan in the browser, copies a concise brief, and opens a prefilled email

## Boundaries

This is an independent planning concept, not an official quote or inspection tool. It does not confirm service fit, structural safety, availability, timing, transport, pricing, or a final estimate.

## Run locally

Open `index.html` or serve this folder with any static file server.
