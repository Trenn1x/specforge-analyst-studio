# Wave Plan

An independent, static MVP prepared as a product concept for Charleston Surf Company.

Wave Plan organizes a prospective surf group’s activity, location/date preference, participant age bands, experience, self-reported water comfort, goals, and open questions into a clean inquiry brief. It deliberately does not assess safety or medical fitness, read live conditions, assign equipment, quote, confirm availability, execute waivers, or create a booking.

The GitHub Pages build uses plain HTML, CSS, and JavaScript with no build step or data storage.
