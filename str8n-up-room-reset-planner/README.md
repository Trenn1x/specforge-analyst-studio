# STR8N UP Room Reset Planner

A standalone, no-build MVP that helps a prospective organizing client turn a broad need into a useful first-call brief.

## What it does

- Captures the client’s situation, first space, desired outcome, obstacle, focus capacity, urgency, preferred format, location, and notes.
- Suggests a possible STR8N UP service lane without diagnosing needs or estimating scope, availability, or pricing.
- Generates a space-specific starter plan and privacy-aware photo checklist.
- Saves a draft locally, copies the brief to the clipboard, or opens a prefilled email to Jennifer.

## Run locally

Open `index.html` directly, or serve this folder with any static HTTP server. No install or build step is required.
