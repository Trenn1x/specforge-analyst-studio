# Shine Bright Phrase & Party Builder — GitHub Pages

Dependency-free public demo of the Phrase & Party Builder MVP.

Open `index.html` in a browser or serve this folder from GitHub Pages. The demo includes the interactive marquee mockup, published-base-price calculation, event/setup intake, setup flags, local save, clipboard fallback, and prefilled email handoff.

This is an independent concept. It does not represent inventory, availability, or a final quote from Shine Bright Marquee.
