# Meeting Green Garden Canvas

A dependency-free GitHub Pages build of an interactive garden-bed intake concept for Meeting Green in Charleston, South Carolina.

## What it does

- maps full sun, part sun, shade, and wet areas on a simple bed grid
- captures bed measurements, irrigation, drainage, style, goals, and maintenance preferences
- adapts the design language, photo checklist, and professional-review flags
- saves locally, copies a concise brief, and opens a prefilled email

## Boundaries

This is an independent planning concept, not an official Meeting Green tool. It does not survey a site, diagnose drainage, identify plants, confirm inventory or service fit, calculate quantities, or provide pricing, availability, installation timing, code, HOA, or safety guidance.

## Run locally

Open `index.html` or serve this folder with any static file server.
