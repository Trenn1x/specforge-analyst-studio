# CharlestonFrames Project Concierge

A working, independent product concept for CharlestonFrames LLC in Hanahan, South Carolina.

The tool helps a prospective customer organize artwork type, rough dimensions, condition flags, display context, design direction, timing, and budget comfort. It then creates:

- a tailored photo checklist;
- questions that still require a professional framer’s judgment;
- a clean, copyable project brief; and
- an email handoff to the business’s public contact address.

It deliberately does **not** inspect artwork, prescribe conservation treatment, quote pricing, confirm materials or availability, reserve an appointment, or report project status.
