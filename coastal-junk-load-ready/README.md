# Load Ready — Pickup Brief Builder

An independent MVP prepared for Coastal Junk Solutions in Summerville, South Carolina.

Customers can build an item list, organize the project location and access route, preview useful pickup photos locally, flag items that need a human answer, record timing preferences, and generate one clean pickup-conversation brief.

The app intentionally does not identify accepted or restricted materials, assess safety, estimate volume or weight, set a price, promise donation or recycling, confirm service area, hold a date, dispatch a crew, upload photos, collect payment, or book a pickup.

## Grounding

The service categories, call-based booking workflow, service-area cities, local/family-owned description, and “same-day often available” language are grounded in Coastal Junk Solutions’ public website:

https://coastaljunksolutions.com/

## Implementation

Plain HTML, CSS, and JavaScript. No dependencies, tracking, accounts, server upload, or data persistence. Photo previews remain on the current device.
