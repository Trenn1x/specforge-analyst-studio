DECISION RECORDS

Tradeoffs made explicit

ADR-001
Keep the public demo static

Pages instantiates BrowserReleaseRepository; the FastAPI client remains an explicit, unhosted option.

ADR-002
Require a human for deployment

Automation may recommend Ready, but it cannot grant the final protected-environment approval.

ADR-003
Separate evidence from verdicts

Gate observations remain distinct from the pure policy that calculates a release recommendation.

FAILURE BOUNDARIES

Designed to degrade clearly

  • API unavailableThe Pages demo stays local; an API-configured client fails visibly.
  • Process restartReference API history resets; the one-instance cap prevents divergent copies.
  • Invalid payloadStrict models reject unknown fields and return a request ID.
  • Duplicate requestIdempotency keys replay the original result or reject conflicting input.
